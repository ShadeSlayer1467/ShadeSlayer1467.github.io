# ReadTech Solutions LLC Website

Static GitHub Pages website for [readtechsolutions.com](https://readtechsolutions.com).

ReadTech Solutions LLC is positioned as a Southern Oklahoma / Texoma business-process automation and custom software company. The site focuses on workflow-first automation: understanding repetitive workplace processes, evaluating whether automation makes sense, and building practical software around existing systems when the business case is real.

## Site Structure

- `index.html` - production single-page website
- `assets/css/readtech-site.css` - original responsive styling
- `assets/js/readtech-site.js` - small navigation/header enhancement script
- `assets/img/readtech-mark.svg` - original ReadTech visual mark and favicon
- `CNAME` - GitHub Pages custom domain configuration
- `robots.txt` and `sitemap.xml` - basic search engine files

## Hosting

The site is designed for GitHub Pages with the custom domain in `CNAME`:

```text
readtechsolutions.com
```
